# xiaohongshu-post

## 任务目标
在小红书发布一篇测试帖子

## 执行步骤
- [completed] 打开小红书APP（包名：com.xingin.xhs）
- [completed] 点击底部导航栏的发布（加号）按钮
- [completed] 选择"写文字"进入文字编辑界面（也可选"从相册选择"发图文）
- [completed] 输入帖子内容（使用剪贴板+粘贴方案B）
- [completed] 依次处理确认弹窗并发布

## 关键操作
### 应用启动
- 包名：`com.xingin.xhs`
- 启动：`am start -p com.xingin.xhs` 或 `android_launch_app(package_name="com.xingin.xhs")`

### 发布流程
1. **底部导航栏**：发布按钮在底栏中间，bounds约[488,2458,732,2604]
   - 其他底栏项：首页[0,2458,244,2604]、市集[244,2458,488,2604]、消息[732,2458,976,2604]、我[976,2458,1220,2604]
   
2. **发布菜单**：点击发布后出现菜单
   - "从相册选择" - 发图文（带图片）
   - "相机" - 拍照发布
   - "写文字" - 纯文字帖
   - "取消"

3. **文字编辑**：选择"写文字"后进入
   - 输入框类型：WebView（无EditText），使用方案B
     - 点击输入框区域聚焦（大约x:610, y:1200）
     - 设置剪贴板：`android_set_clipboard(text="内容")`
     - 按粘贴键：`android_press_key(key="paste")`
   - 点击"下一步"进入预览

4. **预览与发布**
   - 预览页可选卡片样式（基础/科技/边框/备忘/简约）
   - 点击"下一步"进入最终发布页
   - 如有"内容声明"弹窗（添加声明/发布笔记），选"发布笔记"
   - 最终点击"发布笔记"完成发布

### 常见弹窗处理
- **权限弹窗**（MIUI安全中心）：选"本次允许"
- **草稿恢复弹窗**（"继续编辑图文笔记吗？"）：选"存草稿"或按返回
- **内容声明弹窗**（"以下情况需声明，无则直接发布"）：直接点"发布笔记"

### 注意事项
- 小红书输入框是WebView类型，不支持`android_input_text`，必须用剪贴板+粘贴方案
- 资源ID被混淆（`0_resource_name_obfuscated`），需通过text/desc/bounds定位
- 发布流程可能有多层确认弹窗，需逐层处理

## 适用场景
- 需要在小红书发布文字帖
- 需要在小红书发布图文帖（选择"从相册选择"并选图）
- 自动化测试小红书发布流程
