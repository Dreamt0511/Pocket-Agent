# 手机本地大模型 GPU 加速部署 Skill

> 基于小米 17 Pro（骁龙 8 至尊版 + 16GB RAM + Android 16）的完整实践总结

---

## 一、前置条件

| 项目 | 要求 | 你的配置 |
|------|------|---------|
| 芯片 | 骁龙 8 系列（Adreno GPU） | ✅ 骁龙 8 至尊版 |
| RAM | 至少 8GB，推荐 12GB+ | ✅ 16GB |
| 系统 | Android 10+ | ✅ Android 16 |
| 存储 | 模型文件 2-5GB + 编译空间 3GB | 需确认 |
| 网络 | 下载模型和编译依赖 | 需稳定网络 |

---

## 二、核心步骤

### Step 1：安装 Termux（从 F-Droid）

**不要从 Google Play 安装**，那个版本已废弃。

```bash
# 从 F-Droid 下载安装后，更新包管理器
apt update && apt upgrade
```

### Step 2：验证 Vulkan 驱动

```bash
# 安装 Vulkan 工具
apt install vulkan-loader-generic vulkan-tools

# 检查 GPU 是否被正确识别
vulkaninfo | grep -E "(deviceName|driverVersion)"
```

**正确输出**：
```
driverVersion     = 26.0.6 (109051910)
deviceName        = Adreno (TM) 840
```

**如果显示 `llvmpipe`**（软渲染），修复驱动：
```bash
apt remove mesa-vulkan-icd-swrast
apt install mesa-vulkan-icd-freedreno
```

### Step 3：安装编译工具

```bash
apt install git cmake clang ninja spirv-headers spirv-tools glslang
```

### Step 4：克隆并编译 llama.cpp（Vulkan 后端）

```bash
# 克隆最新代码
git clone https://github.com/ggerganov/llama.cpp.git
cd llama.cpp

# 编译 Vulkan 版本（15-30分钟）
cmake -B build -DGGML_VULKAN=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j$(nproc)
```

**编译完成后**，可执行文件在 `~/llama.cpp/build/bin/llama-completion`（新版已改名，不是 `llama-cli`）。

### Step 5：准备模型文件

下载 GGUF 格式模型到手机存储，例如：
- `/storage/emulated/0/本地模型/Qwen3-4B-Instruct-2507.Q4_K_M.gguf`

### Step 6：运行模型（GPU 加速）

```bash
cd ~/llama.cpp
./build/bin/llama-completion -m "/storage/emulated/0/本地模型/你的模型.gguf" \
          -p "你好" \
          -n 128 \
          -ngl 37 \        # 卸载全部 37 层到 GPU
          -t 6 \           # CPU 线程数
          --temp 0.7 \
          --fit off \      # 禁用自动适配（避免 scheduler bug）
          -c 4096          # 限制上下文窗口，防止 KV cache 爆内存
```

---

## 三、关键参数详解

| 参数 | 作用 | 推荐值 |
|------|------|--------|
| `-m` | 模型文件路径 | 完整路径，含空格用引号 |
| `-ngl` | GPU 层数 | 37（全部），或根据内存调整 |
| `-c` | 上下文窗口 | **必须限制**，4096 安全，262144 会闪退 |
| `-t` | CPU 线程 | 6-8，留 2 核给系统 |
| `--fit off` | 禁用自动内存适配 | 必须加，避免 scheduler bug |
| `-n` | 最大生成 token 数 | 按需 |
| `--temp` | 温度 | 0.7 通用 |
| `--no-cnv` | 禁用对话模式 | 测试速度时加 |

## 四、常见问题与解决

### 问题 1：找不到模型文件

**原因**：路径错误或 Termux 无存储权限

```bash
# 开启存储权限
termux-setup-storage
# 用完整路径，含空格用双引号
-m "/storage/emulated/0/本地模型/xxx.gguf"
```

### 问题 2：`cache_k_l0` 错误 / `pre-allocated tensor` 崩溃

**原因**：llama.cpp Vulkan scheduler bug

**解决**：加 `--fit off` 参数，或限制上下文 `-c 4096`

### 问题 3：手机黑屏闪退

**原因**：KV cache 按模型最大上下文（256K）分配，远超 RAM

**解决**：**必须加 `-c 4096`** 限制上下文

| 上下文 | KV cache 大小 | 16GB RAM 能否承受 |
|--------|--------------|------------------|
| 262144 (默认) | ~36 GB | ❌ 闪退 |
| 8192 | ~1.1 GB | ⚠️ 风险 |
| 4096 | ~576 MB | ✅ 安全 |
| 2048 | ~288 MB | ✅ 极致安全 |

### 问题 4：GPU 速度比 CPU 慢

**原因**：移动端 GPU 小批次推理效率低，Vulkan 驱动开销大

**现实**：对于 4B 小模型，**纯 CPU 可能更快或持平**

**建议**：纯 CPU 跑 `-ngl 0 -t 8`，或换 MLC-LLM 框架

## 五、性能参考（你的硬件）

| 配置 | 速度 | 稳定性 |
|------|------|--------|
| GPU 全卸载 (-ngl 37) | ~12 tok/s | 可运行，但效率低 |
| 纯 CPU (-ngl 0, -t 8) | ~12-15 tok/s | ✅ 最稳定 |
| GPU 部分卸载 (-ngl 8) | < 12 tok/s | ❌ CPU-GPU 通信 overhead |

## 六、进阶方向

如果 llama.cpp Vulkan 不满足需求：

| 框架 | 特点 | 难度 |
|------|------|------|
| **MLC-LLM** | 专为移动端设计，自动 GPU/NPU | ⭐⭐⭐ 需编译模型 |
| **MediaPipe** | Google 官方，零门槛 | ⭐ 但模型受限 |
| **QNN (Qualcomm)** | 高通官方 NPU 加速 | ⭐⭐⭐⭐ 需骁龙芯片 + 开发环境 |

## 七、一键启动脚本

在 Termux 中创建 `run-agent.sh`：

```bash
#!/bin/bash
cd ~/llama.cpp
./build/bin/llama-completion \
  -m "/storage/emulated/0/本地模型/Qwen3-4B-Instruct-2507.Q4_K_M.gguf" \
  -p "你好，我是你的AI助手" \
  -n 512 \
  -ngl 0 \
  -t 8 \
  --temp 0.7 \
  -c 4096
```

```bash
chmod +x run-agent.sh
./run-agent.sh
```

---

## 核心结论

> **你的骁龙 8 至尊版已成功启用 GPU（Adreno 840 Vulkan），但对于 4B 小模型，GPU 加速效果不明显（~12 tok/s），不如纯 CPU 稳定高效。限制上下文 `-c 4096` 是避免闪退的关键。如果追求极致速度，建议尝试 MLC-LLM 框架或换用更大的模型（8B+）发挥 GPU 优势。**
