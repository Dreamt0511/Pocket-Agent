# 搜集Boss直聘上深圳地区Agent开发实习岗位的JD信息

## 包名
- Boss直聘：`com.hpbr.bosszhipin`

## 关键坐标（基于1220×2656分辨率）
- **首页"城市"按钮**：`[779,499,954,587]` → 中心点 (866, 543)
- **城市搜索输入框**：`[65,166,1011,277]` → 中心点 (538, 221)
- **城市搜索结果"深圳"**：`[0,294,1220,462]` → 中心点 (610, 378)
- **确定按钮**：`[429,2412,1155,2555]` → 中心点 (792, 2483)
- **搜索框**：`[315,166,1155,277]` → 中心点 (735, 221)
- **搜索建议"agent开发实习"**：`[610,882,893,938]` → 中心点 (751, 910)
- **搜索结果页城市筛选"重庆"→"深圳"**：城市按钮 `[33,440,208,586]` → 中心点 (120, 513)；切换城市按钮 `[922,150,1181,313]` → 中心点 (1051, 231)
- **岗位卡片点击**：根据UI树动态获取bounds计算中心点

## 操作步骤

### 1. 打开Boss直聘APP
1. `mcp_call(tool_name="android_launch_app", arguments={"package_name": "com.hpbr.bosszhipin"})`
2. `mcp_call(tool_name="android_wait_for_idle", arguments={"timeout_ms": 2000})`

### 2. 切换地区为深圳
**方案一：首页切换（推荐）**
1. 获取UI树：`android_get_ui_tree(filter="all")`
2. 点击底部筛选栏的"城市"按钮（坐标 866, 543）
3. 等待页面加载：`android_wait_for_idle(2000)`
4. 点击搜索框（坐标 538, 221）
5. 设置剪贴板：`android_set_clipboard("深圳")`
6. 粘贴：`android_press_key("paste")`
7. 点击搜索结果中的"深圳"（坐标 610, 378）
8. 点击底部"确定"按钮（坐标 792, 2483）
9. 等待页面跳转

**方案二：搜索结果页切换（当搜索结果页城市不对时）**
1. 在搜索结果页点击城市筛选标签（如"重庆"，坐标 120, 513）
2. 点击右上角"切换城市"（坐标 1051, 231）
3. 在搜索框输入"深圳"（粘贴方式同上）
4. 点击"深圳"搜索结果

### 3. 搜索agent开发实习岗位
1. 点击顶部搜索框（坐标 735, 221）
2. 可直接点击搜索建议中的"agent开发实习"（坐标 751, 910）
3. 或输入关键词后搜索
4. 等待搜索结果加载：`android_wait_for_idle(2000)`

### 4. 查看岗位详情和JD
1. 从搜索结果列表中点击岗位卡片（根据UI树获取bounds计算坐标）
2. 查看完整JD描述
3. 截图保存：`android_screenshot(quality=80)`
4. 返回搜索结果页：`android_press_key("back")`
5. 重复查看其他岗位

### 5. 保存JD信息
1. 截图保存岗位详情页面
2. 或用file_write将JD信息整理为文档

## 失败经验
1. **首页切换城市后，搜索页城市未同步**：不要在首页切换城市后直接搜索，搜索页的城市筛选是独立的。需要在搜索结果页重新设置城市筛选（点击城市标签 → 切换城市 → 选择深圳）
2. **paste粘贴无效**：在部分输入框中paste快捷键可能不生效。此时可以改用`android_input_text`直接输入短文本（如"深圳"只有2个字符）
3. **搜索结果页回到首页**：连续按back键可返回首页，但注意不要退出了APP
4. **坐标变化**：不同屏幕分辨率下坐标需重新从UI树计算，禁止硬编码坐标
5. **搜索建议随账号变化**：不同账号的历史搜索和推荐搜索词不同，如果找不到建议词，手动输入关键词
6. **"城市"筛选标签页结构差异**：首页的城市选择和搜索结果页的城市选择UI结构不同，分别处理

## 适用场景
- 需要在Boss直聘上搜集特定城市特定岗位的JD信息
- 需要对比多家公司的招聘要求、薪资范围
