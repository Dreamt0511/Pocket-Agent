# DeepSeek对话技能

## 一、基础信息
- **包名**：`com.deepseek.chat`
- **启动命令**：`am start -p com.deepseek.chat`（可能失败，建议用android_launch_app）
- **应用类型**：标准WebView

## 二、核心操作流程

### 1. 启动应用
```python
mcp_call(tool_name="android_launch_app", arguments={"package_name": "com.deepseek.chat"})
```

### 2. 开始新对话
- 点击底部输入框区域激活键盘
- 或使用"开启新对话"按钮（右上角）

### 3. 输入文本（三步法 - 标准WebView）
DeepSeek使用标准WebView，需使用**方案B**输入：
1. 设置剪贴板内容：`android_set_clipboard`
2. 点击输入框聚焦
3. 按paste键粘贴：`android_press_key(key="paste")`

### 4. 发送消息
- 点击发送按钮（右下角，desc: "发送"）

### 5. 查看回复
- 回复内容会显示在对话区域
- 可使用复制、喜欢、不喜欢、分享、重新生成等功能

## 三、坐标参考（基于1220x2656屏幕）
- 底部输入框区域：[72,2271,1148,2434]（中心点约610,2352）
- 发送按钮：[1058,1448,1110,1500]（中心点约1084,1474）
- 开启新对话按钮（右上角）：[1097,196,1175,274]

## 四、界面元素
- **快速模式/专家模式选择**：首次进入需选择对话模式
- **深度思考按钮**：底部左侧
- **智能搜索按钮**：底部中间
- **上传文件按钮**：底部右侧
- **语音切换按钮**：最右侧

## 五、失败经验
1. **启动失败**：Shell命令`am start`可能因权限失败，改用`android_launch_app`
2. **输入方案**：DeepSeek使用标准WebView，不能用`android_input_text`，必须使用剪贴板+paste
3. **输入框定位**：点击底部输入区域（约y=2352）激活键盘后，输入框会上移到约y=1313
4. **发送按钮位置**：发送按钮在输入框右侧，坐标约[1058,1448,1110,1500]

## 六、注意事项
1. 联网搜索功能需手动开启，不会自动启用
2. 知识截止到2025年5月
3. 纯文本模型，无法直接识别图片内容（但可读取图片中的文字）
4. 支持多轮对话，上下文会保留
