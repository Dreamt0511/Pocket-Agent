### 2. 流式输出架构

#### LLMManager 类
```python
class LLMManager:
    def __init__(self):
        self.provider = None
        self.config = self.load_config()  # 从.env和系统环境加载
    
    async def stream_chat(self, user_message: str, system_prompt: str = None):
        """流式对话主入口"""
        if not self.provider:
            self.setup_provider()
        
        messages = [{"role": "system", "content": system_prompt}, 
                   {"role": "user", "content": user_message}]
        
        async for chunk in self.provider.stream_chat_completion(messages):
            yield chunk
```

#### 提供商流式实现
- **CustomProvider**: 支持类似 LongCat 的流式API
- **OpenAIProvider**: 标准OpenAI流式接口
- **OllamaProvider**: 本地模型流式生成
