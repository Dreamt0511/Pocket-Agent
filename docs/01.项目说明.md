# Pocket-Agent 项目文档

## 项目介绍

Pocket-Agent 是一个轻量级的移动端AI代理项目，参考了 learn-claude-code 和 CyberClaw 的设计模式，专注于在移动设备上运行。

## 特色

- ✅ 轻量化：代码精简，体积小，适合移动端
- ✅ 日常记忆：每天自动生成Markdown记忆文件
- ✅ Rich UI：美化的终端界面，提供优质交互
- ✅ 模块化：工具、技能、代理核心分离
- ✅ 可扩展：支持自定义工具和技能
- ✅ 移动优化：适合在手机、平板等设备上运行
- ✅ LLM集成：支持LongCat-Flash-Lite等多种模型

## 快速开始

### 1. 安装依赖

```bash
cd "/storage/emulated/0/手机agent开发/Pocket-Agent"
pip install -r requirements.txt
```

### 2. 配置LLM模型（选填）

💻 **方法1: 使用配置工具**
```bash
python setup_llm.py
# 选择1，输入API信息
```

💻 **方法2: 手动设置环境变量**
```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加：
export LLM_PROVIDER=custom
export LLM_BASE_URL=https://api.longcat.bytedance.com
export LLM_API_KEY=your_api_key_here
export LLM_MODEL=longcat-flash-lite

# 然后生效
source ~/.bashrc
```

### 3. 运行快速测试

```bash
python quick_test.py
```

### 4. 启动主程序

```bash
python main.py
```

### 5. 运行测试套件

```bash
python tests/test_agent.py
```

## 使用方法

### 基本交互

启动后，你可以和代理进行对话：

```
𝌈 你: 查看一下当前目录的文件
🤖 代理: 我会调用directory_list工具来查看目录内容...
```

### 常用指令

| 指令 | 说明 |
|--------|--------|
| `help` | 查看常用指令帮助 |
| `记忆搜索 [关键词]` | 搜索历史记忆 |
| `查看天气` | 调用天气工具 |
| `磁盘信息` | 查看系统状态 |
| `任务列表` | 查看任务管理 |
| `llm [query]` | 使用LLM模型 |
| `quit` | 退出程序 |

### LLM测试

```
> llm 你是谁？
> llm 介绍下Python编程
```

### 记忆系统

- 每天自动创建一个Markdown记忆文件
- 所有对话、工具调用都会记录到记忆
- 支持标签和重要性编辑
- 支持根据关键词搜索历史记忆

## LLM集成

Pocket-Agent 支持多种LLM提供商：

- **LongCat-Flash-Lite** (推荐) - 轻量级版本，适合移动端
- **OpenAI GPT-3.5-turbo** - 标准版本
- **Ollama 本地模型** - Phi-3, Mistral 等

### 配置LongCat-Flash-Lite

```bash
python setup_llm.py  # 选择1，输入API信息
```

或者手动设置环境变量：

```bash
export LLM_PROVIDER=custom
export LLM_BASE_URL=https://api.longcat.bytedance.com
export LLM_API_KEY=your_api_key_here
export LLM_MODEL=longcat-flash-lite
```

### 测试LLM连接

```bash
python setup_llm.py  # 选择2，测试连接
# 或者在对话中输入:
> llm 你好
```

## 自定义开发

### 添加新工具

在 `tools/` 目录下创建新文件：

```python
from core.agent import tool

@tool(
    name="my_tool",
    description="我的自定义工具",
    parameters={
        "type": "object",
        "properties": {
            "param1": {"type": "string", "description": "参数1"}
        },
        "required": ["param1"]
    }
)
def my_tool(param1: str) -> str:
    return f"执行结果: {param1}"
```

### 添加新技能

在 `skills/` 目录下创建新文件：

```python
def register(agent):
    @agent.add_skill
    def my_skill(input_data: str) -> str:
        return f"执行技能: {input_data}"
```
