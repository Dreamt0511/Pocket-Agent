### douyin-like-comment 新技能内容
1. **包名**：`com.ss.android.ugc.aweme`
2. **启动方式**：`am start -p com.ss.android.ugc.aweme`
3. **搜索流程**：点击搜索按钮 → 搜索框为原生 EditText（方案A输入）→ 资源ID `com.ss.android.ugc.aweme:id/et_search_kw`
4. **点赞操作**：进入视频后点击右侧心形点赞按钮
5. **评论操作**：评论框为原生 EditText（方案A）→ 输入内容后点击发送
6. **滑动切换**：`android_swipe` 从底部向上滑
7. **返回操作**：`android_press_key(key="back")`

### 关键经验
- 抖音搜索框和评论框都是原生 EditText，可直接使用方案A（`android_input_text`）
- 搜索后默认在"综合"标签，需切换到"用户"标签找账号
- 点赞前需验证是否已点赞，避免重复操作
- 滑动切换视频使用 `android_swipe` 从底部向顶部滑动
