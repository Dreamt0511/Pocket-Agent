电脑端测试有两种方案，可以根据你的需求选择：

---

## 🚀 方案A：使用云端API（最简单，无需本地跑模型）
适合快速测试Agent功能，不需要占用电脑资源跑模型。

### 步骤：
1. **修改.env配置**：
   ```env
   # ==================== 📱 手机端默认配置（本地llama-server）====================
   # 注释掉下面三行
   # DEFAULT_LLM_BASE_URL=http://127.0.0.1:8080/v1
   # LLM_API_KEY=dummy
   # LLM_MODEL=gelab-zero-4b-preview
   # LLM_TEMPERATURE=0.7
   # LLM_MAX_TOKENS=8000

   # ==================== 🌐 电脑端配置（云端API）====================
   # 取消下面三行的注释，用你已有的API配置
   DEFAULT_LLM_BASE_URL=https://api.longcat.chat/openai/v1
   LLM_API_KEY=ak_2NP8EQ3Pv27
   LLM_MODEL=LongCat-Flash-Lite
   ```

2. **测试连接**：
   ```bash
   python test_llm.py
   ```
   看到"LLM响应正常"说明配置正确。

3. **运行主程序**：
   ```bash
   # Windows 临时设置UTF-8编码（避免中文乱码）
   set PYTHONUTF8=1
   python main.py
   ```

---

## 📱 方案B：电脑本地跑llama-server（和手机环境100%一致）
适合测试和手机端完全相同的环境，确保功能在手机上也能正常运行。

### 步骤：
1. **电脑上编译llama.cpp**（和手机端用相同版本）
2. **启动llama-server**，参数和手机端保持一致：
   ```bash
   ./build/bin/llama-server \
     -m "/你的模型路径/gelab-zero-4b-preview.gguf" \
     --mmproj "/你的模型路径/GELab-Zero-4B-preview-f16.mmproj" \
     --host 0.0.0.0 \
     --port 8080 \
     -ngl 99  # 根据你的电脑显卡调整，N卡可以全开
   ```

3. **.env保持默认手机端配置即可**，不需要修改：
   ```env
   DEFAULT_LLM_BASE_URL=http://127.0.0.1:8080/v1
   LLM_API_KEY=dummy
   LLM_MODEL=gelab-zero-4b-preview
   ```

4. **测试运行**：
   ```bash
   python test_llm.py
   python main.py
   ```

---

## 💡 Windows 环境特殊说明
如果遇到中文乱码或编码错误：
1. 建议使用 **WSL2** 运行，和Termux环境最接近，不会有编码问题
2. 或者使用 **PowerShell 7+**，默认使用UTF-8编码
3. 临时解决：运行命令前先执行 `set PYTHONUTF8=1`

两种方案都可以正常测试，推荐先用方案A快速验证Agent逻辑是否正确，再用方案B测试和手机完全一致的环境。


### 📦 安装方式
在项目根目录下执行：
```bash
pip install -e .
```

### 🎯 使用效果
1. **解决所有相对导入问题**：模块导入不再报错，`from .config import xxx`等相对导入完全正常工作
2. **全局命令启动**：安装完成后，在任何目录下直接输入命令即可启动：
   ```bash
   pocket-agent
   ```
   不需要再进入项目目录执行`python main.py`
3. **依赖自动安装**：会自动安装`pyproject.toml`中声明的所有依赖，不需要单独执行`pip install -r requirements.txt`
4. **开发模式**：`-e`是可编辑模式，修改代码后立即生效，不需要重新安装

### 📝 可选依赖安装
如果需要使用额外功能，可以单独安装：
```bash
# Ollama本地模型支持
pip install langchain-ollama

# 系统信息查询增强
pip install psutil
```

### 🗑️ 卸载方式

```bash
pip uninstall pocket-agent
```
