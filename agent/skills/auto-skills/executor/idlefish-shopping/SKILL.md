# 闲鱼APP购物技能

## 一、基础信息
- **包名**：`com.taobao.idlefish`
- **启动命令**：`am start -p com.taobao.idlefish`
- **注意**：启动时可能弹出应用选择对话框，需点击"仅一次"按钮。

## 二、核心操作流程

### 1. 搜索商品
1. 点击搜索框（resource_id: `com.taobao.idlefish:id/search_bar_layout`）
2. 输入搜索关键词：
   - **方案A（推荐）**：搜索框可识别为原生 EditText，使用 `android_input_text(text="关键词")` 直接输入
   - **快速方案（推荐）**：进入搜索页后，直接点击推荐词（如"索尼a6000"）可快速搜索，无需手动输入
   - **备选方案**：使用方案B（点击聚焦→set_clipboard→press_key paste）
3. 点击搜索按钮或推荐词执行搜索

### 2. 商品详情页
1. 在搜索结果中找到目标商品，点击进入
2. 查看价格、描述、卖家信息
3. 点击"我想要"按钮进入聊天（坐标参考：[850,2451,1168,2581]）

### 3. 聊天界面（UCWebView/Rax类型输入框）
1. 输入框特征：无原生 EditText，placeholder 为"想跟TA说点什么..."
2. **输入方案**：闲鱼聊天使用 UCWebView/Rax，**必须使用方案C（键盘粘贴建议）**
   - 方案A（android_input_text）和方案B（press_key paste）均无效，不要尝试
   - 操作步骤：
     a. `android_tap(x=输入框中心x, y=输入框中心y)` — 点击输入框聚焦
     b. `android_wait_for_idle(timeout_ms=3000)` — 等待键盘弹出
     c. `android_set_clipboard(text="要发送的内容")` — 存入剪贴板
     d. `android_tap(x=输入框left+40, y=输入框bottom+50)` — **点击键盘上的粘贴按钮**
        - 如果失败，按 `paste_y += 20` 递增重试
        - 粘贴按钮通常在输入框左下方区域
3. 发送按钮：desc="发送"，坐标参考：[993,1455,1188,1579]
4. **验证方法**：操作后 get_ui_tree，检查输入框 text 是否从 placeholder 变成目标内容

### 4. 卖家个人主页
1. 在聊天界面点击卖家名称/头像进入主页
2. 查看信用档案、评价、公告
3. 评价页面可按标签筛选（全部、好评、差评）
4. **查看差评**：差评可能被隐藏，需要滚动到评价区域并点击"差评"标签

## 四、失败经验与关键发现
1. **搜索框输入**：闲鱼搜索框是原生 EditText，可用 `android_input_text` 直接输入（方案A有效）。
2. **推荐词点击**：搜索页面会出现热门推荐词，直接点击推荐词比手动输入更快更可靠。
3. **聊天输入框**：闲鱼聊天输入框是 UCWebView/Rax 类型，**方案A（input_text）和方案B（press_key paste）均无效**，必须用方案C（点击键盘粘贴按钮）。
4. **键盘粘贴按钮位置**：不同键盘类型（搜狗/百度/系统键盘）粘贴按钮位置有差异：
   - 通常在输入框左下方（left+40, bottom+50 左右）
   - 如失败，按 `paste_y += 20` 递增重试，最多试3次
   - 如果仍然失败，尝试点击输入框附近区域触发粘贴弹窗
5. **应用选择弹窗**：启动时可能出现"选择要使用的应用"弹窗，需点击"仅一次"按钮关闭。
6. **评价查看**：差评可能被隐藏或只显示部分，需要主动点击"差评"标签筛选查看。

## 五、注意事项
1. 卖家可能设置自动回复，不代表真实在线状态。
2. 查看卖家公告了解发货时间和规则。
3. 商品价格可能包含或不包含配件，需仔细阅读描述。
4. 联系卖家时，建议直接在聊天输入框中输入问题，不要使用快捷短语（如有）。
5. 从聊天界面返回商品详情或卖家主页时，可使用导航栏的返回按钮。
