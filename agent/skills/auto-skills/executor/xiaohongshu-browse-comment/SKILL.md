# xiaohongshu-browse-comment

## 任务目标
去小红书浏览一篇agent相关的帖子，根据帖子内容作出相应的回复，然后下滑找一个其他评论进行回复。

## 执行步骤
- [completed] 打开小红书APP
- [completed] 搜索"agent"相关的内容
- [completed] 选择一篇相关的帖子浏览
- [completed] 阅读帖子内容并作出相应回复
- [completed] 下滑查看评论区
- [completed] 选择一个评论进行回复

## 关键操作
### 应用启动
- 包名：`com.xingin.xhs`
- 启动：`am start -p com.xingin.xhs`

### 搜索功能
1. **搜索框定位**：点击顶部搜索框（约x:540, y:120）
2. **输入搜索词**：使用剪贴板+粘贴方案（WebView类型输入框）
   - 设置剪贴板：`android_set_clipboard(text="agent")`
   - 点击搜索框聚焦后粘贴：`android_press_key(key="paste")`
3. **执行搜索**：点击搜索按钮（约x:960, y:120）

### 帖子选择与浏览
1. **搜索结果页**：等待加载完成后选择第一个相关帖子
2. **帖子详情页**：点击帖子封面或标题进入详情页
3. **内容阅读**：滑动屏幕阅读完整内容

### 评论功能
1. **输入评论**：点击评论输入框（约x:540, y:2100）
   - 使用剪贴板+粘贴方案输入评论内容
   - 设置剪贴板：`android_set_clipboard(text="评论内容")`
   - 点击输入框后粘贴：`android_press_key(key="paste")`
2. **发布评论**：点击发布按钮（约x:900, y:2100）

### 评论区浏览
1. **下滑查看**：从帖子内容下滑进入评论区
2. **选择评论**：点击具体评论进行回复
3. **回复评论**：在评论输入框输入回复内容并发布

### 关键坐标
- 搜索框：x:540, y:120
- 搜索按钮：x:960, y:120  
- 评论输入框：x:540, y:2100
- 发布按钮：x:900, y:2100

### 注意事项
- 小红书输入框均为WebView类型，必须使用剪贴板+粘贴方案
- 搜索和评论都需要等待页面加载完成再操作
- 帖子选择优先选择标题包含"agent"的内容
- 评论内容要结合帖子主题，避免无关回复
- 页面滑动要控制力度，避免过度滑动

## 适用场景
- 需要在小红书搜索特定关键词并浏览相关内容
- 需要对小红书帖子进行评论和互动
- 自动化测试小红书的搜索、浏览、评论流程
- 社交媒体内容分析和用户行为研究
