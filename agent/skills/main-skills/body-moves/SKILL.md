# 身体动作指导

**优先级**：先查预设动作文件 → 搜索记忆 → 现场编排。

---

## 一、执行动作流程

### 1. 查找预设动作（优先）

在本目录下查找匹配的 .json 动作文件：

```
本目录：agent/skills/main-skills/body-moves/
```

- 按用户说的动作名直接匹配文件名
- 文件名不完全匹配时，读取文件内容根据 `description` 字段模糊匹配
- 找到后直接用 `body_script` 执行

### 2. 搜索记忆（次选）

预设中没有时，用 `search_memory` 搜索：
- 关键词：动作名（如"坐下""打招呼""跳舞"）
- 描述词：动作特征（如"挥手""弯腰""踢腿"）
- 记忆中可能保存了之前用户要求记住的动作数据

### 3. 现场编排（兜底）

预设和记忆都没有时，根据以下参考现场编排：

**编排参考**：详见 body_control_tool.py docstring 中的各部位方向说明和参考值

**执行方式**：
- **必须用 `body_script` 执行**，不要多次调用 `control_body`。`body_script` 接收完整动作数组一次性处理，多次单独调用 control_body 会因为 HTTP 请求累积延迟导致动作卡顿不流畅
- 只有单步动作（如"抬一下右手"）才用 `control_body`

**编排要点**：
- 先 `body_idle()` 归位，再开始动作
- 多部位协调：手臂配合手肘、大腿配合小腿、动作配合躯干和头部
- 积极配合身体动作：挥手时身体微倾、转身时配合拧腰、点头时配合前倾
- 节奏控制：快速 0.08~0.15s、普通 0.2~0.3s、慢动作 0.4~0.6s
- 对称动作注意左右方向差异

编排完成后执行并询问用户是否满意。满意则保存（见下方）。

## 二、记住动作

用户说"记住这个动作""保存动作"等时，写入本目录下 .json 文件：

**文件名**：`动作名称.json`

**文件内容**：
```json
{
  "name": "动作名称",
  "description": "描述词，包含动作特征关键词，用于后续搜索匹配",
  "moves": [
    {"action":"bone","part":"right_arm","z":60,"delay":0.3},
    {"action":"idle"}
  ]
}
```

**同时保存到记忆**：

用 `save_memory` 工具保存一条动作记忆，内容包含动作名、描述词、完整 moves JSON 数据和文件路径。这样 Agent 通过 `search_memory` 搜索动作名或描述词就能直接找到动作数据。

**要求**：
- `name`：用户指定的动作名
- `description`：必填，写清楚动作特征和关键词，方便模糊搜索
- `moves`：完整的原始动作数据，不修改不简化
- 保存后在本文件末尾的预设动作索引表中添加一行
